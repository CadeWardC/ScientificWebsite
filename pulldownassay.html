Pulldown Assay

Upload a blot or gel image, drag a box over a band, and read the pixel intensity profile across it.

1. Load an image

🖼️

Click to choose a file or drag one here

JPG, PNG, or TIFF

2. Draw the boxes

Drag on the image to draw a box; drag inside it to move it, or drag a handle to resize it. Press Ctrl+A to add another box of the same size — added boxes are locked to the same height level and slide sideways only, so lanes stay comparable. Click a box to select it, Delete removes the selected one. Rename a box in the Box name field or by double-clicking its tab below — after Ctrl+A the name field is already focused, so type the name and press Ctrl+A again for the next box. Each point on the plot averages one pixel-wide line inside the box, running perpendicular to the profile direction. Intensity is always inverted, so dark pixels read as high signal.

3. Intensity profile

Peaks

Each box finds its own peaks, wherever they sit in that lane. The shaded spans are what get integrated — drag any dashed edge on the plot, or type the offsets here. Windows re-detect themselves as you move a box until you adjust that box by hand.
